# Project instructions

This repository is a portable technical tutor and Markdown knowledge library. Keep the teaching methodology canonical in `TUTOR.md` and knowledge in `knowledge/`.

For teaching, learning coaching, technical explanations, guided debugging, or revision, read `TUTOR.md` before responding. Then read `knowledge/README.md` and consult only relevant index entries, progress records, and concept references. For unrelated tasks, do not load the tutor methodology or library.

After meaningful teaching, search for an existing concept before creating one. Update the reference, index, concise learning progress, and revision queue as relevant. Verify writes before claiming they succeeded. Use local Markdown; do not add dependencies or external services.
