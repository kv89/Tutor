# Project instructions

This repository is a portable technical tutor and Markdown knowledge library. The teaching methodology is canonical in `plugin/skills/techtutor/TUTOR.md`, the library format in `plugin/skills/techtutor/library-format.md`, and this folder's knowledge in `knowledge/` and `review/`.

For teaching, learning coaching, technical explanations, guided debugging, or revision, read `plugin/skills/techtutor/TUTOR.md` before responding. Then read `plugin/skills/techtutor/library-format.md` and consult only relevant index entries, progress records, and concept references. This folder is a folder library, so use folder mode. For unrelated tasks, do not load the tutor methodology or library.

After meaningful teaching, search for an existing concept before creating one. Update the reference, index, concise learning progress, resume note, and revision queue as relevant. Verify writes before claiming they succeeded. Keep the library as plain Markdown; running the tutor needs no installed packages or external services.
