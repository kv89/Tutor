# Review sets

Use `revision-queue.md` to track concepts worth revisiting. For interview or exam preparation, select relevant concepts from `knowledge/index.md` and `knowledge/progress.md`, especially recorded gaps and misconceptions. Ask about assessment scope or timing only when it changes the review plan; never invent a date.

Build concise recall prompts, worked problems, comparisons, or application exercises that link to canonical concept references. Keep answers separate from prompts where practical. Do not copy long explanations into review notes. Add an assessment-specific review file only when it will be reused, and link to concepts instead of duplicating them.
